# 家庭任务冒险岛

访问地址：https://petrology.cn/family-adventure/

手机和电脑均可使用。页面包括今日、计划、成长、奖励和家庭；支持成员新增、资料编辑、删除及恢复。家庭至少保留一位成员，新增成员从零积分开始。

本目录为无需构建的静态网页。用静态 HTTP 服务器托管本目录即可本地体验。未登录时数据保存在当前浏览器；配置 Supabase 后可使用邮箱密码登录，多个设备登录同一家庭账号即可同步。家人角色不是独立账号，暂不包含家长审批或独立家人账号邀请。删除成员会隐藏成员并保留原有数据，可在家庭页面恢复。

番茄钟结束获得活力，任务完成另获成长积分；奖励兑换提供倒计时和记录。成员增删后共同目标人数自动更新。

已检查：计时奖励、任务显式完成、重复领取保护、兑换扣除、成员增删改与恢复、删除计时成员、历史数据归属、最后一位成员保护及本地保存。

## 账号与同步

- `cloud-config.js` 只包含 Supabase 项目 URL 和可公开的 Publishable Key，不得加入管理员密钥。
- `supabase/schema.sql` 定义账号私有数据表、行级访问权限和带版本检查的同步事务。账号只能读写自己的数据。
- Supabase Auth 的 Site URL 和 Redirect URLs 应设置为 `https://petrology.cn/family-adventure/`；邮箱确认保持启用。
- Supabase 默认邮件仅向项目团队邮箱投递。其他邮箱注册、密码找回需要在控制台配置自己的 SMTP 服务。
- 首次登录可选择导入本机数据或创建空白家庭。云端不会自动覆盖本机未登录数据。
- 登录后每 5 秒检查更新；页面重新获得焦点或网络恢复时也会同步。离线改动保存在当前设备，联网后重试。
- 同时修改产生版本冲突时暂停写入，保留本机备份，由用户载入云端进展后继续。不会静默合并奖励或覆盖较新版本。
- 当前设备显示的成员独立保存，切换角色不会切换其他设备的显示成员。

运行 `node family-adventure/tests/cloud.test.cjs`（从仓库根目录）检查数据导入、双设备同步、重复奖励保护、离线重试、冲突备份和退出隔离。
