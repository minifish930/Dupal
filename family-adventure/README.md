# 家庭任务冒险岛

访问地址：https://petrology.cn/family-adventure/

手机和电脑均可使用。页面包括今日、计划、成长、奖励和家庭；支持成员新增、资料编辑、删除及恢复。家庭至少保留一位成员，新增成员从零积分开始。

本目录为无需构建的静态网页。用静态 HTTP 服务器托管本目录即可本地体验。数据仅保存在当前浏览器 localStorage，不包含跨设备同步、密码保护或家长审批。删除成员会隐藏成员并保留原有数据，可在家庭页面恢复。

番茄钟结束获得活力，任务完成另获成长积分；奖励兑换提供倒计时和记录。成员增删后共同目标人数自动更新。

已检查：计时奖励、任务显式完成、重复领取保护、兑换扣除、成员增删改与恢复、删除计时成员、历史数据归属、最后一位成员保护及本地保存。
